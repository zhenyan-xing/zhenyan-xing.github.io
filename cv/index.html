  • Jun 2026 - Present

    HomoPrefix: Homolog-Conditioned Protein Sequence Generation
    Tsinghua University
    Supervisor: Prof. Ziqi Gao
    • Developed HomoPrefix for protein sequence generation conditioned on homologous proteins, using PoET representations to provide sequence context to a ProGen2 decoder.
    • Trained and compared generators using compressed reference summaries or residue memory, alongside a model without homologous context, under different sequence prefix lengths.
    • Evaluated the use of homologous context on 317 test proteins from families represented in training, using mismatched references while holding targets, prefixes, and model weights fixed.
  • Sept 2026 - Oct 2026

    Xi’an, China

    AbFUSE: Joint Antibody Optimization for Discriminating Similar Targets
    Xi’an Jiaotong University
    Supervisor: Fei Wang
    • Investigating whether molecular dynamics supervision can improve downstream sequence generation, using antibody design and target discrimination as the application.
    • Built supervision from ATLAS trajectories covering 835 protein systems and adapted Protenix to predict residue fluctuations, distance variability, and correlated motion.
    • Developed dynamics prediction heads using Protenix pair representations and evaluated them using frozen backbone and mismatched correlation controls.
    • Implemented a workflow to optimize one antibody sequence against intended and related off targets using frozen structure and affinity predictors.
